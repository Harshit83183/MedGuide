# MedGuide Emergency Protocols

1. RED triage or SOS tap → advise **108 (ambulance) / 112 (national emergency)** first.
2. 1-Tap SOS posts GPS + note to `sos_alerts`, WhatsApp/call links for saved contacts.
3. ER first-aid cards: bleeding control, no spine movement, chest-pain seating, seizure safety.
4. Never wait on the app in emergency — call helpline, then use app to share location.
5. Helplines: 108 ambulance, 112 emergency, 1091 women, 1098 child.
